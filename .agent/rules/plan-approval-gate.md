# Plan-approval gate (always on)

You MUST NOT create, edit, move, rename or delete any file, run any install/build/format command that writes to disk, or fetch and install anything, until the user has approved a written plan for that change in this conversation.

Allowed WITHOUT approval (read-only): reading files, searching the workspace, viewing pages in the browser, taking screenshots, running read-only commands (ls, cat, git status, git diff, git log), asking questions.

Everything else needs approval of a plan first.

When asked to make any change, your FIRST response is a plan, not a change. End the plan with the exact line:
"Reply APPROVE to proceed, or tell me what to change."
Then STOP and wait.

Approval phrases that count: "APPROVE", "approved", "go ahead", "proceed with the plan". Approval covers ONLY the plan as written. Silence, thumbs-up on other messages, or earlier approvals do not count.

If the user asks for changes to the plan, revise it, show what changed, and ask again. Do not start.

During execution, if you discover the plan is wrong, incomplete or needs a file/step not listed, STOP, report it, and submit an amended plan. Do not improvise.

Never combine unrelated changes. One approved plan = one scope.
