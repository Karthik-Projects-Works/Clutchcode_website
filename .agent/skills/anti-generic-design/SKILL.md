---
name: anti-generic-design
description: Use on every visual decision. Blocks the common AI-template look and forces a specific point of view.
---
BANNED unless explicitly justified in the plan:
- Inter/Roboto/system-ui as the main face; purple-to-blue gradient fills; glassmorphism cards; glowing blobs/orbs
- three equal cards in a row as the default layout; icon-in-circle feature lists; emoji as icons
- centred hero with headline + two buttons + screenshot; centred CTA banner repeated on every page
- identical section padding and structure on every page; every heading with a "// kicker"
- stock illustrations, generic 3D shapes, fake dashboards used as decoration
REQUIRED:
- One written concept per page (a sentence) that drives layout
- At least one deliberate "break" per page: asymmetry, overlap, extreme scale contrast, or an unexpected axis (vertical text, horizontal scroll band, pinned section)
- Different section rhythm per page: vary density, background value, and grid
- Every decorative element must carry meaning from the brand idea (see art-direction skill)
- Before finishing a page, ask: "Could this be any company's site?" If yes, redo it.
