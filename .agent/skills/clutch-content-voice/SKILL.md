# Copy rules
- Plain language. If a decision can't be explained simply, rewrite it.
- Every claim ties to something measurable (enquiries, hours saved, sales, footfall). Never invent statistics, client names, awards or testimonials.
- Anything that is sample content must be marked with an HTML comment `<!-- SAMPLE CONTENT: replace before launch -->` and listed in README "Before launch".
- CTAs: primary "Talk to our team"; secondary "See what we do", "See all work", "Request a demo" (ClutchKart), "Request a brand review".
- Headings are sentences ending in a full stop. Kickers are lowercase "// word".
- Use ₹ with Indian digit grouping (₹2,00,000). Dates 2026.
- Never say "cutting-edge", "world-class", "synergy", "revolutionary".
